promptctl demo
$ promptctl create "analyze my SaaS idea for the Dutch market. be critical"
<context>
You are a seasoned venture analyst with experience evaluating
500+ business ideas. Your job is to give an honest, evidence-based
assessment - not encouragement.
</context>
<task>
1. Market size and growth trajectory
2. Competitive landscape with named competitors
3. Unit economics and path to profitability
4. Kill criteria - signals to stop pursuing this
</task>
<constraints>
- Be ruthlessly honest. If the idea is bad, say so directly.
- Challenge every assumption. Default to skepticism.
</constraints>
Features

Prompt engineering on autopilot

Every prompt follows best practices by default. Structure, personas, constraints, and output formats - injected automatically based on what you're trying to do.

⚡

create

Turn raw, unstructured intent into a fully structured prompt. Auto-detects task type, assigns expert personas, infers implied needs, and adds quality constraints.

📂

templates

Reusable YAML templates with variable substitution. Global library for your patterns, project-level overrides for team consistency. Define once, use everywhere.

📄

file-aware

Pass --file=path and the content, filename, and language are auto-injected. Review code, debug errors, explain modules - all with one command.

🎯

task detection

Automatically classifies your intent into 11 task types: business analysis, code review, debugging, architecture, planning, writing, and more. Each gets specialized structure.

🔁

pipe anywhere

Output goes to stdout. Pipe to Claude CLI, OpenAI, copy to clipboard, or redirect to a file. Fits into any workflow without lock-in.

⚙️

zero config

Single binary, no runtime dependencies. Run promptctl init and you have 5 battle-tested templates immediately. Extend when you need to.

How it works

From rough idea to structured prompt

The create command runs a deterministic, rule-based engine. No LLM call needed - it applies prompting best practices at the speed of your disk.

1

Classify

Detects task type from keywords. Business analysis, code review, debugging, architecture - 11 categories, each with specialized handling.

→
2

Decompose

Splits your intent into distinct actions. Infers implied needs you didn't ask for. Detects tone - "be critical" triggers skepticism constraints.

→
3

Structure

Wraps in XML tags with expert persona, task breakdown, output format template, and quality constraints. Ready to paste or pipe.

Starter templates

Battle-tested prompts out of the box

Five templates ship with promptctl init. Each encodes real-world prompt engineering patterns.

🔍

review

Security-first code review with line-number references, severity ranking, and concrete fix suggestions.

promptctl review --file=auth.ts
🐛

debug

Root cause analysis, not symptom chasing. Explains why the bug occurs and how to prevent recurrence.

promptctl debug --file=api.ts --error="TypeError..."
🏗

arch

Architecture decision records with options matrix, trade-off analysis, and concrete migration steps.

promptctl arch --problem="REST vs gRPC"
📝

commit

Conventional commit messages from diffs or descriptions. Imperative mood, scoped, under 72 chars.

promptctl commit --changes="added retry logic"
📚

explain

Code explanation at three depth levels: overview, detailed, and deep-dive. Built for knowledge transfer.

promptctl explain --file=parser.go --depth=detailed
✨

+ your own

Create custom templates with promptctl add. YAML format with variables, conditionals, and auto-file reading.

promptctl add my-template
